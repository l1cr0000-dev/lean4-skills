# Paper Sync

Use this visible Codex skill to publish approved paper planning or progress to
GitHub Issues. Follow the canonical [paper-sync command](../../commands/paper-sync.md).
Keep `.formalization/` manifests, evidence, Lean files, and git history as the
recoverable source of truth; never import tracker edits silently.
